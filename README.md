# SCT_WD_2
AuraCalc is a modern neon-style calculator built using HTML, CSS, and Vanilla JavaScript that provides basic arithmetic operations, percentage calculations, keyboard support, and a responsive glassmorphism user interface. It features a dynamic history panel that stores recent calculations, smooth button animations with ripple effects, and mobile-friendly responsiveness for a seamless experience across devices. Designed with a futuristic UI and lightweight performance, AuraCalc is fast, visually appealing, and easy to use without requiring any external libraries or frameworks.
